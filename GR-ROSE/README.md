自律走行ロボットのための統合ビジョン・制御システム
1. 概要
本プロジェクトは、特定の競技（KXRロボットを用いた玉入れ）をターゲットとした、自律走行ロボットのための統合的な画像認識・行動計画システムです。PCの高度な処理能力でカメラ映像を解析し、ロボット（マイコン）と確実性の高い同期通信を行うことで、ロボットが自律的にボールを収集し、ゴールに運ぶまでの一連の動作を実現します。

このシステムは、ロボットの「目（Perception）」と「頭脳（Decision Making）」の役割を担います。

2. 主な特徴
リアルタイム3D物体認識:

カメラ映像から、複数のカラーボール（赤・緑・青）とロボットに貼り付けられたArUcoマーカーをリアルタイムで検出します。
カメラキャリブレーションと姿勢推定技術を用いて、これらのオブジェクトが現実世界のどこにあるかを3次元座標（mm単位）で特定します。
高度な処理内容の可視化:

ロボットやボールの3D空間における位置、さらにロボットが現在目標としているボールを画面上にリアルタイムで描画します。
これにより、システムの内部状態が直感的に理解でき、デバッグや動作のチューニングが非常に効率的に行えます。
同期的で信頼性の高いロボット制御:

PCとマイコン間は、信頼性の高いTCP通信による「サービス形式」で連携します。
PCが動作指示を出すと、マイコン側での物理的な動作が完了するまでPCは待機し、マイコンからの「完了報告」を受けてから次の指示を出します。これにより、計画と実際の動きがズレることを防ぎ、確実な動作を実現します。
洗練された行動計画アルゴリズム:

前方探索: 常にロボットより前にあるボールのみをターゲットとします。
動的リターゲティング: 移動中も常に最も近いボールを再探索し、状況の変化に柔軟に対応します。
ターゲットロック: ボールに一定距離まで近づくとターゲットをロックし、見失っても最後の位置に向かい続けます。
比例制御による接近: 目標に近づくほど移動量を減らすことで、スムーズかつ正確な位置決めを行います。
マルチスレッドによる安定動作:

高フレームレートが要求される「画像処理」と、時間のかかる「ロボット制御」を別々のスレッドで並列処理しています。
これにより、ロボットの動作完了を待っている間もカメラ映像がカクつくことなく、滑らかな表示と安定した認識を両立させています。
3. システムアーキテクチャ
本システムは、役割を明確に分離した階層化アーキテクチャを採用しています。

PC側 (Python): 高度な計算処理を担当

メインスレッド: カメラ映像の取得、画像処理、可視化など、高速な処理に専念します。
制御スレッド: ActionPlannerを実行し、低頻度で時間のかかるロボットへの指示と完了待機に専念します。
モジュール群:
ActionPlanner: ロボット全体の行動戦略を決定する「頭脳」。
RobotController: マイコンとのTCP通信を担う「神経」。
各種Detector/Translator: 画像から3D座標を算出する「目」。
マイコン側 (Arduino/GR-ROSE): 物理的な動作を担当

PCからのTCP接続を待ち受けるTCPサーバーとして機能します。
受信したコマンド（例: "up", 50.0）を解釈し、ICSプロトコルでサーボモーターを直接制御します。
動作が完了したら、PCに「完了報告」を返信します。

5. セットアップと環境構築
PC側
Python環境:
Python 3.x をインストールしてください。
依存ライブラリのインストール:
ターミナルで以下のコマンドを実行し、必要なライブラリをすべてインストールします。
Bash

pip install -r requirements.txt
これにはOpenCVやNumPyが含まれます。
マイコン側
Arduino IDE:
Arduino IDEをインストールし、GR-ROSEボードが使えるように設定してください。
ライブラリのインストール:
以下のArduinoライブラリをライブラリマネージャ等でインストールしてください。
ICS.h (双葉電子工業のサーボ用)
WiFiEsp.h (ESP-W5500 Wi-Fiモジュール用)
事前準備：カメラキャリブレーション
Calilbration/フォルダ内のchesspattern_7x10.pdfを印刷します。
同フォルダのREADME.md の指示に従い、01-01_calibrateCamera.py を実行してカメラのキャリブレーションを行います。
生成されたカメラパラメータ（MTX_CALIB）と歪み係数（DIST_CALIB）をmain.pyの定数部分にコピー＆ペーストしてください。（現在はサンプル値が入力されています）
6. 実行方法
マイコンの準備:
robot_action.ino内のWi-Fi設定（SSIDとパスワード）を自身の環境に合わせて変更します。
Arduino IDEを使ってrobot_action.inoをGR-ROSEボードに書き込みます。
シリアルモニタを開き、マイコンがWi-Fiに接続し、IPアドレスが表示されるのを待ちます。
PC側の準備:
module/robot_controller.py内のIPアドレスを、上記で表示されたマイコンのIPアドレスに書き換えます。
システムの起動:
ターミナルでmain.pyを実行します。
Bash

python main.py
操作:
カメラ映像のウィンドウが表示されます。
キャリブレーションで使ったチェス盤をカメラに写し、キーボードの1キーを押して、世界座標系を設定します。
座標軸（赤:X, 緑:Y, 青:Z）がチェス盤の角に表示されれば、設定完了です。ロボットが自律的に動作を開始します。
qキーを押すと、プログラムが安全に終了します。
7. 動作のチューニング
ロボットの細かい挙動はmodule/action_planner.pyの__init__メソッド内にあるパラメータで調整できます。

GOAL_POSITION: ゴールの座標。
PICKUP_OFFSET_X, PICKUP_OFFSET_Y: ボールを掴む際の停止位置の微調整。
POSITION_TOLERANCE: どのくらいのズレを許容するか。
MOVE_PROPORTIONAL_GAIN: 接近速度の調整（値を大きくするとより速く近づく）。
TARGET_LOCK_DISTANCE_X: どのくらい近づいたらターゲットをロックするか。
